# Downstream Maintenance

- `development.md` — branch model, extension rules, upstream synchronization,
  conflict handling, database rollout, and release maintenance.
- `fork-deltas.yaml` — active downstream deviations that touch upstream-owned
  behavior or integration points.
- `sgp1-operations.md` — single-node release, restore rehearsal, readback, and
  rollback evidence contract.
- `.agents/runtime/README.md` — task execution, risk, verification, and closeout
  contract for agents and humans.

These documents govern only the downstream fork. They do not replace upstream
project identity, attribution, contribution rules, or architecture contracts.
